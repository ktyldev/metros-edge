# Metro's Edge (working title)

Submission for [the long jam for short games](https://itch.io/jam/20-second-game-jam-2026).

# Description

Can you make your train? Sprint, slide and leap _à la_ Mirror's Edge to make it from one train to another in 20 seconds or less!

# Project Setup

Godot project is inside `metros-edge` folder to leave space for ancillary scripts/docs/whatever next to it.

## Light baking

This project uses static global illumination, which requires baking a lightmap (a large texture) in the engine before deploying. This lightmap is not stored in the project repo as it is huge and regenerated often. It can be generated by selecting the LightmapGI node in `environment.tscn` and pressing the `Bake Lightmaps` button which appears above the 3D view.
